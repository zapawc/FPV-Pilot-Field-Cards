# Print-ready cards

This directory contains the print-ready PNG masters for the FPV Pilot Field Cards deck.

Each card face is designed for **3 × 5 inch landscape printing at 300 DPI** (1500 × 900 px). Print at **100% / actual size** rather than “fit to page” to preserve the intended dimensions.

The `08A` and `08B` glossary cards are intended to be printed as opposite sides of one duplex card.

For source traceability and QR-validation notes, see [`../docs/MANIFEST.md`](../docs/MANIFEST.md) and [`../docs/QA_REPORT.md`](../docs/QA_REPORT.md).
